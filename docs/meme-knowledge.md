# 中文梗知识的导入方案

梗词库是可检索的本地知识包，不是每轮对话都附带的提示词，也不等于对模型进行训练。核心可以在本机索引词条，只在遇到相关候选时把少量释义交给分类器。精确匹配与索引查询本身不消耗模型 token；让模型结合语境判断时仍会消耗该次模型调用的 token。

## 可评估的起始资料

- [CHIME](https://github.com/yuboxie/chime)：仓库提供 1,458 个短语梗的释义、出处、例句、类别及冒犯性标记，并标注 MIT 许可。论文说明资料来自 2020–2024 年的梗解释，经过整理、信息提取和人工检查。适合作为可评估的首批候选，不代表覆盖全部新梗或群内黑话。
- [chinese-meme-dict](https://github.com/re-skylar/chinese-meme-dict)：仓库自述提供 10,808 条，并以 CC BY 4.0 发布，要求保留署名；其说明释义由 AI 撰写。可作为可选补充包，导入前应抽样检查准确性并保留来源和署名。

当前不随核心仓库打包任何第三方梗语料；后续应按独立词包管理并遵守各自许可。

## 分类边界

词条命中只表示“可能涉及梗”，不能直接断定本条消息是玩笑。同一个表达可能按字面使用，也可能是反讽、引用或群内特有用法。分类需要结合上下文、说话关系和用户纠正；“是梗”也不等于“没有记忆价值”。

词条至少应保存表达及别名、简短释义、类型、例句、来源、许可、更新时间、歧义和冒犯性标记。群内私有梗默认保留在本地，不自动加入公共词包。
